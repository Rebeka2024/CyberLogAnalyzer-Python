# 🔐 Cyber Security Log Analyzer (Python)

A Python-based security log analysis tool that reviews login activity and identifies suspicious authentication attempts.

## 📌 Project Overview

CyberLogAnalyzer simulates a basic security monitoring tool used to review login records. The program analyzes successful and failed login attempts while identifying suspicious activity based on location.

This project was created to practice Python programming concepts while exploring cybersecurity and system monitoring workflows.

## 🚀 Features

- Analyze login activity
- Count successful and failed attempts
- Detect suspicious locations
- Generate security reports
- Interactive command-line interface

## 🛠️ Technologies Used

- Python
- Visual Studio Code
